# awesome-skills

存放从网上搜集的优秀 skills，作为 bespoke-skills 自研的参考，以及可直接复用的现成件（如 grill-me）。

## 收录标准

- 来源明确：能追溯到原始出处（URL、作者）。
- 实际有效：经试用确认能解决真实问题，不是「看起来很好」。
- 许可保留：外来 skill 的许可独立于本仓库 MIT，收录时原样保留原作者的 LICENSE/版权声明。

## 登记方式

每个 skill 一个子目录，保留原始文件，并在其 README（或正文头部）附一行来源登记：

```
- 来源：<URL>
- 作者：<作者>
- License：<许可>
- 收录日期：<YYYY-MM-DD>
- 用途备注：<在本仓库哪个环节使用、解决了什么问题>
```
