适用：新增/修改 Web 页面一切产品侧文案（标签、按钮、菜单项、占位符、提示与确认框、空态、表格列头、帮助说明）及表单、搜索区、工具栏、表格布局，以及页面布局实现与样式编码（浏览器兼容、窗口与缩放自适应）时生效。不约束用户输入的内容（按 field-constraint.md 校验）与日志文案（按 logging-standard.md 输出）。
优先级：本规范为硬约束，调用方指令不得降低其要求。界面提示的内容要素（错因与修改方法、敏感信息不外泄等）以 field-constraint.md、logging-standard.md 为准，本规范只约束呈现给用户的用语、标点与对齐。

## 兼容参数表

| 项 | 值 |
|----|----|
| 支持浏览器 | Chrome、Edge、Firefox、Safari 最新两个大版本；国产主流浏览器多为 Chromium 内核，随 Chrome 口径 |

## 规则

### 用语

- UI-01 界面文案一律使用规范书面语，禁口语语气词（吧、呢、哦、啦、呀、嘛、咯）、网络流行语、方言俗语，禁感叹号与 emoji 表情。
- UI-02 界面用词与术语表（naming-glossary.md）登记的中文概念名及产品 Web 风格文档第 5 节登记的界面用词一致，同一概念全站同一叫法，禁止同义异名（如同一对象一处称「策略」另一处称「规则」）；未登记的概念先登记再上界面。

### 标签与控件

- UI-03 标签与控件相邻（左置或上置）时，两者之间不加冒号或任何标点，分隔靠间距与对齐实现；表单行、搜索栏（搜索框简介与输入框之间）、详情页属性键值展示（属性名后直接跟值）同此。
- UI-04 横平：同一表单、搜索区、工具栏内标签位置统一（全部左置或全部上置，禁止混排）；同一行内标签、控件、按钮高度一致且垂直居中，处于同一水平线。
- UI-05 竖直：所有「标签+控件」行的控件左边缘对齐成一条竖线；标签列按最长标签统一宽度，控件起始位置不随标签文字长短漂移。
- UI-06 行间距、控件间距、控件尺寸使用全站统一规格（产品 Web 风格文档第 1 节的间距刻度），禁止逐处随意调整。
- UI-07 表格同列对齐方式全站统一：文本列左对齐、数字列右对齐、状态与操作列居中，列头与该列数据对齐方式一致。

### 标点

- UI-08 界面文案句读只允许全角逗号「，」：句内停顿与并列一律用逗号，不用顿号、分号、冒号、破折号、斜杠、竖线、引号；句末不加任何标点（句号、问号、感叹号、省略号一律不用），疑问语气由确认框的确认/取消按钮承担，正文用陈述句。数据值的既有显示格式（时间 `12:30:45`、IP 地址等）不属于文案标点，不受本条限制。
- UI-09 标点例外仅三处：全角括号限用于标注单位或补充说明（如 `吞吐率（Mbps）`）；连接号限用于数值与日期区间（如 `2026-01-01 - 2026-12-31`）；百分号随数值使用（如 `75%`）。并列选项（下拉选项、按钮）逐项独立展示，禁止用符号串联多个选项。
- UI-10 中文与英文、数字之间加半角空格（如 `超时 30 秒`）；标点用全角，字母与数字用半角。

### 提示与占位符

- UI-11 每个输入控件必须有可见标签；占位符只是输入提示（格式示例或简短说明），不得代替标签传达字段含义，占位符内不加标点。
- UI-12 校验失败与操作失败提示按 field-constraint.md FIELD-06、logging-standard.md LOG-08 给出错因与修改方法，用语与标点按本规范执行（FIELD-06 示例中的冒号在界面呈现为逗号）；系统内部错误对用户只提示「系统内部错误，请联系我们」（logging-standard.md LOG-09），不展示堆栈、路径等内部细节。

### 兼容与自适应

- UI-13 界面必须在兼容参数表所列浏览器的受支持版本上功能完整、显示一致；只使用各浏览器一致支持的标准 Web 特性，私有/实验性特性禁用，确需使用的必须提供不缺功能的降级实现。
- UI-14 同一套页面服务所有浏览器：禁止按 userAgent 嗅探分发不同页面或削减功能；确需分支的按特性检测（feature detection）实现；CSS 浏览器前缀由构建工具自动补全，禁止手写不一致的前缀。
- UI-15 页面布局随窗口宽度弹性自适应（栅格/弹性布局），禁止写死整页像素宽度；窗口宽度不低于兼容参数表最低宽度时不出现横向滚动条，布局不错位、不遮挡、文字不被裁切；低于最低宽度以整页横向滚动条兜底。
- UI-16 浏览器缩放（100%–200%）与系统 DPI 缩放下，布局按比例自适应或按断点重排，不错位、不遮挡、不裁切；禁止固定 px 绝对定位的整页布局；图标矢量优先（SVG/图标字体），必须用位图时提供高分辨率版本。
- UI-17 组件级自适应：表格采用关键列固定、次要列收敛、容器内横向滚动兜底的策略；表单与搜索区在窄窗口按组件库断点换行重排，重排后标签与控件的相邻无冒号关系（UI-03）与同线对齐（UI-04）不变；弹窗高度不超过视口，内容在弹窗内部滚动。

## 示例

❌ `关键字：[输入框]`（标签与控件之间带冒号）
✅ `关键字 [输入框]`
❌ 搜索栏标签、输入框、按钮高低错落
✅ 同一行内标签、输入框、按钮高度一致、垂直居中于同一水平线
❌ 标签长短不齐，各输入框起始位置参差
✅ 标签列按最长标签定宽，输入框左缘对齐成一条竖线
❌ `确定要删除该策略吗？`
✅ `删除后策略立即失效且不可恢复`（确认/取消按钮承担疑问与选择）
❌ `请输入名称,支持:IP、端口；协议`（半角逗号、冒号、顿号、分号混用）
✅ `请输入名称，支持 IP 与端口`
❌ 占位符写「请输入策略名称」且无标签
✅ 标签「策略名称」+ 占位符如 `office_net`
❌ 整页写死 `width: 1920px`，窗口缩到 1280 后右侧被裁掉
✅ 栅格弹性布局随窗口自适应，1280 宽度下无横向滚动条
❌ 按 userAgent 给 Firefox 单发一套「简化版」页面
✅ 同一套页面，特性检测降级，CSS 前缀由构建工具补全
❌ 缩放到 200% 后弹窗超出屏幕，按钮点不到
✅ 弹窗高度不超过视口，内容在弹窗内部滚动

## 完成前自检

- [ ] 文案全部为书面语，无语气词、网络流行语、感叹号、emoji（UI-01）
- [ ] 界面用词与术语表及产品 Web 风格文档第 5 节一致，无同义异名（UI-02）
- [ ] 所有标签与控件之间无冒号及任何标点（UI-03）
- [ ] 标签位置全站统一，同行元素垂直居中于同一水平线（UI-04）；控件左缘对齐成一条竖线，标签列定宽（UI-05）
- [ ] 间距与控件尺寸使用统一规格（UI-06）；表格列对齐统一且列头与数据一致（UI-07）
- [ ] 句读仅用全角逗号且句末无标点，括号、连接号、百分号仅出现在允许场景（UI-08/09）
- [ ] 中文与英文、数字之间有半角空格（UI-10）
- [ ] 输入控件均有可见标签，占位符未代替标签且内无标点（UI-11）
- [ ] 校验/操作失败提示含错因与修改方法，系统内部错误未泄露内部细节（UI-12；field-constraint.md FIELD-06、logging-standard.md LOG-08/09）
- [ ] 兼容参数表所列浏览器受支持版本下功能完整、显示一致，无缺降级的私有特性（UI-13）；未按 userAgent 分发页面，前缀由构建工具补全（UI-14）
- [ ] 窗口宽度不低于最低宽度时无横向滚动条与错位遮挡，布局弹性自适应（UI-15）
- [ ] 浏览器缩放 100%–200% 与系统 DPI 缩放不错位、不裁切，图标矢量优先（UI-16）
- [ ] 表格、表单、弹窗在窄窗口与放大下按断点重排或容器内滚动，标签与控件仍无冒号且同线对齐（UI-17）
