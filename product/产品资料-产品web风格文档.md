# 产品 Web 风格文档（模板）

适用：新产品实例化时填写本模板；AI 生成/修改产品 Web 界面时，与 standards 规范一并作为依据。
优先级：本文档只做绑定与补充，不得降低 standards 下任何规范的要求；与规范冲突时以规范为准。

使用说明：「【待填】」为必须按具体产品填充的槽位。全部槽位填完后删除本行说明。

## 1. 设计系统

| 项 | 值 |
|----|----|
| UI 框架及版本 | 【待填：如 Vue 3】 |
| 组件库及版本 | 【待填：如 Element Plus】 |
| 图标库 | 【待填】 |
| 色彩令牌 | 【待填：主色；功能色——成功 / 警告 / 危险 / 信息的色值】 |
| 字体与字号层级 | 【待填：正文 / 标题 / 辅助说明】 |
| 间距与圆角 | 【待填：基础间距刻度、圆角档位】 |
| 暗色模式 | 【待填：支持 / 不支持；支持则附暗色令牌】 |

## 2. 布局模板

- 整体骨架：【待填：如左侧导航 + 顶部栏 + 内容区】
- 列表页标准布局：【待填：筛选区 / 表格 / 操作列 / 分页的排布约定】
- 表单页标准布局：【待填：分组 / 标签对齐 / 必填标识 / 按钮位置】
- 详情页/仪表盘标准布局：【待填】
- 适配范围：【待填：浏览器范围与最低窗口宽度；不填按 ui-standard.md 兼容参数表默认值】

## 3. 交互惯例

| 场景 | 约定 |
|------|------|
| 表单校验错误呈现 | 【待填：inline 红字 / toast；须满足「错在哪 + 怎么改」（FIELD-06）】 |
| 危险操作确认 | 【待填：删除/下发是否二次确认及文案格式】 |
| 加载 / 空态 / 错误态 | 【待填：骨架屏 / loading / 空态样式 / 错误重试】 |
| 操作成功反馈 | 【待填：toast 位置与时长】 |

## 4. 与规范的界面联动点

| 联动点 | 约定 |
|--------|------|
| 密码输入框 | 【待填：规则提示文案（对应密码参数表）、强度提示样式】 |
| 敏感字段展示 | 界面掩码固定 `******`（与日志脱敏 LOG-11 口径一致） |
| 状态色 ↔ 日志等级 | 成功=INFO、提醒=WARNING、失败=ERROR/ALERT：取第 1 节对应功能色 |
| 字段显示格式 | 时间格式【待填：如 YYYY-MM-DD HH:mm:ss】；速率/流量单位显示【待填】；ID 是否展示（如 policy_id 显不显示）【待填】 |
| 界面文案用语与标点 | 按 ui-standard.md 执行：书面语、句读仅用全角逗号且句末无标点、标签与控件间无冒号、标签控件横平竖直对齐 |
